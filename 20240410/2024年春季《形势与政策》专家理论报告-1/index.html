2024年春季《形势与政策》专家理论报告-1

专家领学-理论报告（必做环节）：每位形策（2）课程学生以线上或线下方式聆听1次专家理论报告（计为4理论学时），专家报告的相关具体信息参见课程后续通知。此外，结合教育部最新版《高校“形势与政策”课教学要点》，定期向学生推送学习材料，作为学生理解专家理论报告及最新形势政策的辅助材料。要求每位学生围绕专家理论报告或学习材料内容，在期末时提交1篇不少于800字的“学习心得”。

政党与现代化的理论与实践——马克思主义的解释与中国经验

中共中央党校经济学部教授 李鹏

主要内容：

政治基础：政党领导型国家的性质

哲学基础：政治与经济的唯物辩证关系

一、政治基础：政党领导型国家的性质

  • 无产阶级政党领导是建立社会主义国家的政治前提
  • 孙中山领导中国国民党开始以党建国的探索
  • 中国共产党领导开创中国革命和现代化建设经济工作
  • 政党领导后发国家现代化是一个普遍的世界现象

1、无产阶级政党领导是建立社会主义国家的政治前提

(1)政党的性质与特征

  • 西方资产阶级政党一般都不承认自己的阶级性，认为政党是资产阶级政治中“表达民意的组织”，是“全民的党”，是“超阶级的组织”。
  • 马克思主义政党理论认为：政党是阶级的组织，是阶级斗争发展到一定历史阶段的产物，是一定阶级的利益代表。

(2)共产党是代表人民利益的无产阶级政党

  • 1847年6月成立共产主义者同盟，成为科学社会主义运动史上第一个无产阶级政党。
  • 恩格斯为同盟撰写了党纲《共产主义原理》。
  • 同盟以“推翻资产阶级，建立无产阶级统治，消灭旧的以阶级对立为基础的资产阶级社会和建立没有阶级、没有私有制的新社会”为目标。
  • 用“全世界无产者，联合起来”的新口号代替原来阶级观点模糊的“人人皆兄弟”的旧口号。

1848年《共产党宣言》

  • 是马克思主义关于无产阶级政党的第一份完整的纲领性文件。
  • “共产党人没有任何同整个无产阶级的利益不同的利益。在无产阶级和资产阶级的斗争所经历的各个发展阶段上，共产党人始终代表整个运动的利益”。
  • “共产党人是各国工人政党中最坚决的、始终起推动作用的部分”。
  • “共产党人最近的目的是使无产阶级形成为阶级，推翻资产阶级的统治，由无产阶级夺取政权”

(3)列宁新型无产阶级政党理论的提出

  • 理论源头：1881年马克思《给查苏利奇的复信》
  • 背景：落后国家能否跨越“卡夫丁峡谷”
  • 1902年列宁在《怎么办》，1903年《进一步，退两步（我们党内的危机）》、《唯物主义和经验批判主义》等文章中指出：
  • “在通常情况下，在多数场合，至少在现代的文明国家内，阶级是由政党来领导的”“党是阶级的先进觉悟阶层，是阶级的先锋队”。进而提出社会主义“将首先在一个或者几个国家内获得胜利”的论断。
  • 邓小平指出，“列宁有个完整的建党的学说，正是因为列宁建立了那么个好的党，才能取得十月革命的胜利，建立了第一个社会主义国家。”

苏共领导下苏联模式（斯大林模式）体制性弊病

  • 政治上高度集权，缺乏民主性；
  • 经济上计划体制，严重排斥市场机制；
  • 产业结构上过度强化重工业、忽视农业和轻工业的发展；
  • 意识形态上对马克思主义僵化理解。

2、孙中山领导中国国民党以党建国

  • 孙中山从早先的“效法英美”，彻底转向“以俄为师”，效仿苏联，提出并探索以党建国治国思想理论。
  • 孙中山把当时的社会民众分为先知先觉者、后知后觉者、不知不觉者三类，认为虽然一部分社会精英具备了自觉建党建国的政治觉悟和意识，但由于后知后觉者和不知不觉者的麻木不醒，形不成从上而下的政治合力，也就无法建立一个现代意义上的共和国。只有先知先觉的先进分子组成现代政党，进而宣传、组织、引领广大民众，才能取得革命的最终胜利。
  • “政党是代表一定阶级、阶层或集团的根本利益，由其中一部分最积极的分子组成，有共同的政治主张（理论和纲领），采取共同的行动，为夺取和巩固政权而联合起来的有组织有纪律的政治组织”。
  • “要改造国家，非有很大力量的政党，是做不成功的”。

“立党救国”、“以党建国”、“以党治国”三个历史和理论逻辑紧密相联的“党——国”理论

  • “国家必有政党，一切政治始能发达”。
  • “若无政党，则民权不能发达，不能维持国家，亦不能谋人民之幸福，民受其毒，国受其害，是故无政党国家，国家有腐败，民权有失败之患”。
  • 党的作用有三。“一以养成多数政治上之智识，而使人民有对于政治上之兴味；二组织政党内阁，执行其政策；三监督或左右政府，以使政治之不滥乎正规”。
  • “所谓以党治国，并不是要党员都做官，然后中国才可以治；是要本党的主义实行，全国人都遵守本党的主义，中国然后才可以治。简而言之，以党治国，并不是用本党的党员治国，是用本党的主义治国”。

1924年《中国国民党第一次全国代表大会宣言》

  • 孙中山接受中国共产党的建议，对国民党进行改组，实现国共合作，召集有共产党人参加的第一次全国代表大会。
  • “近世各国所谓民权制度，往往为资产阶级所专有，适成为压迫平民之工具。若国民党之民权主义，则为一般平民所共有，非少数人所得而私之”。
  • 为了实现三民主义，国民党仿效苏联建党建国模式，提出“联俄、联共、扶助农工”的三大政策，构建以党建国的政治蓝图。

3、中国共产党领导中国革命和建设的经济工作

  • 党的一大上通过《中国共产党第一个纲领》，把实现共产主义作为党的最高理想和最终目标，确定中国共产党的名称，“推翻资本家阶级的政权”“承认无产阶级专政”“消灭资本家私有制”“社会革命”等党的重要目标、途径等根本原则。
  • 1926年毛泽东在《纪念巴黎公社的重要意义》文中指出：巴黎公社存在不过七十二天，何以失败这么快呢？其中一个原因是“没有一个统一的集中的有纪律的党作指挥——我们欲革命成功，必须势力集中行动一致，所以有赖于一个有组织有纪律的党来发号施令”。

1939年至1940年初，毛泽东经过大量创造性理论思考后，第一次阐述了关于党的领导和国家建设的一系列思想，形成了新民主主义治党建国理论的基本原则和科学体系。

  • 大生产运动的巨大成效：1942年底，陕甘宁边区生产自给率达到60%以上，1943年更是达到了100%。边区农民在这一年已经不需要缴纳抗日救国的公粮，边区财政也开始出现结余。经济上的成绩对军事力量补充1944年体现得最为明显，全国19个敌后抗日根据地基本度过困难时期，根据地人口增长到8000万人，正规部队发展到47万人。
  • 毛泽东总结大生产运动时辩证指出：国民党对根据地的封锁，除了消极的坏的一面以外，还产生了一个积极的方面，那就是促使我们决心自己动手解决供给的问题，而“其结果则是居然达到了克服困难的目的。学得了经营经济事业的经验”，“特别重要特别值得指出的，是我们学得了经营经济事业的经验，这是不能拿数目字来计算的无价之宝”。

4、政党领导后发国家现代化是一个普遍的世界现象

  • 沃勒斯坦：《现代世界体系》，“中心——外围”理论：
  • “现代世界经济是资本主义的世界经济，于是世界经济便划分为中心国家和边缘地区。中心地区的君主们通过建立官僚制、发展军事力量、建构合法性等途径极大地强化国家机器，使国家在资本积累和管理剩余价值方面起决定性作用。”

萨缪尔·亨廷顿：“强政府理论”

  • 《变化社会中的政治秩序》是亨廷顿理论的奠基之作，提出第三世界国家走向现代化的“强政府理论”。
  • 第三世界国家在进行现代化变革的过程中，要根除国内政治的动荡和衰朽，就必须建立起强大的政府，舍此无他路可走。
  • 强有力政党能够以一个制度化的公共利益来取代四分五裂的个人利益。
  • 一个没有政党的国家也就没有产生持久变革和化解变革所带来的冲击的制度化手段，其在推行政治、经济、社会现代化方面也就受到极大限制。

社会主义、强力政党与现代化

  • 罗荣渠：《现代化新论一世界与中国的现代化进程》，“内源——外源”理论，提出殖民地国家现代化轨迹是“衰败化——半边缘化——革命化——现代化”的“四重奏”，“通过长期的革命化的重组过程，缓慢地走向工业化——现代化”的道路。
  • 保罗·斯威齐：社会主义作为一种方法，它在按整个社会的利益来利用现代技术的生产力方面，其所固有的优越性将得到清楚的证明。
  • “发展型国家”理论：日本自民党、新加坡人民行动党。

二、哲学基础：政治与经济的唯物辩证关系

  • 任何国家中政治与经济是有机整体的性质
  • 资本主义上层建筑与发展
  • 汉《盐铁论》看政治与经济
  • 社会主义现代化关键在于辩证处理好政治与经济关系

1、政治与经济的有机整体性质

(1)马克思主义的整体性分析方法和范式

  • 马克思：“唯物史观本来就是将社会作为一个有机系统来研究的”；“每一个社会中的生产关系都形成一个统一的整体”。
  • 卢卡奇《历史与阶级意识》：“正统马克思主义并不意味着无批判地接受马克思研究的结果。马克思主义问题中的正统仅仅是指方法。唯物辩证法是一种革命的辩证法，坚持整体的具体的统一性。”

(2)政治与经济是矛盾对立统一的有机体

  • “现在的社会不是坚实的结晶体，而是一个能够变化并且经常处于变化过程中的有机体”——《资本论》
  • 任何一个具体的社会有机体，都是历史的，具有从低级向高级发展的动态生成性特征，是漫长的发育、发展和自我创造过程的产物，是一个由无序到有序、由简单到复杂、由低级到高级的演进过程。

(3)经济基础对包括政治在内上层建筑决定作用

  • 物质生产力一定发展阶段相适合生产关系。生产关系总和构成社会经济结构，即有法律的和政治的上层建筑竖立其上并有一定的社会意识形式与之相适应的现实基础。
  • 不是人们的意识决定人们存在，相反，是人们的社会存在决定人们的意识。

(4)政治对经济的反作用力

  • 马克思：“如果政治权力在经济上是无能为力的，那么我们何必要为无产阶级的政治专政而斗争呢？”
  • 恩格斯：“政治权力在对社会独立起来并且从公仆变为主人以后，可以朝两个方向起作用。或者它按照合乎规律的经济发展的精神和方向发生作用，在这种情况下，它和经济发展之间没有任何冲突，经济发展加快速度。或者它违反经济发展而发生作用，在这种情况下，除去少数例外，它照例总是在经济发展的压力下陷于崩溃”。

2.资本主义上层建筑手段加快资本主义的发展进程

  • 原始积累的不同因素，多少是按时间顺序特别分配在西班牙、葡萄牙、荷兰、法国和英国。
  • 在英国，这些因素在17世纪末系统地综合为殖民制度、国债制度、现代税收制度和保护关税制度。
  • 所有这些方法都利用国家权力，也就是利用集中的、有组织的社会暴力，来大力促进从封建生产方式向资本主义生产方式的转化过程，缩短过渡时间。
  • 暴力是每一个孕育着新社会的旧社会的助产婆。暴力本身就是一种经济力。

3.从《盐铁论》看中国古代大一统封建国家与政治经济辩证关系认知：（公元前81年汉昭帝，辩论汉武帝时期“盐铁官营、酒榷、均输、平准、算缗、告缗”）

  • 桑弘羊：坚持盐铁官营
    1. 官营废除，导致边境军费不足；
    2. 私营易成为诸侯反叛经济基础，促进豪强势力膨胀，“一家害百家”；
    3. “平万物而便百姓”；
    4. 获取外国资财，削弱敌国实力。

文学、贤良方：罢盐铁官营

  1. 与民争利，应还利于民；
  2. 官府制作铁器规则统一，质次价高；
  3. 均输、平准，官吏强征贱买、奸商囤积；
  4. 礼义是立国根基，权势财利是为政残贼。

4.我国经济制度变迁与社会主义经济建设

  • 1949年
    国民经济恢复：“四面八方”新民主主义制度政策
  • 1953年
    向社会主义过渡：“一化三改”政策制度
  • 1958年
    社会主义建设：“重工业优先”的社会主义计划经济体制
  • 1978年
    改革开放：建设“小康社会”的社会主义市场经济体制
  • 2017年
    新时代：实现“美好生活”的社会主义基本经济制度
